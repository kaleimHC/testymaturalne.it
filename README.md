# testymaturalne.it

Quiz do nauki teorii na maturę z informatyki.

**Live:** https://testymaturalne.it

---

## Warianty

| Wariant | Opis |
|---|---|
| **Estetyczny** | Ciepła paleta Gruvbox - stonowany, przyjemny motyw. |
| **Klasyczny** | Bez rozpraszaczy - oszczędny, neutralny układ, nic nie odciąga uwagi od pytań. |
| **Egzaminacyjny** | Wygląd inspirowany arkuszem CKE - biała kartka, Arial i fioletowa belka nad zadaniem. |

## Dane

- 213 pytań z matur CKE z informatyki
- Typy pytań: jednokrotny wybór (ABCD) i Prawda/Fałsz
- Wzory matematyczne renderowane przez KaTeX

## Funkcje

- Losowanie kolejności pytań
- Zapis postępu w `localStorage`
- Tryb ciemny / jasny
- Podsumowanie z siatką wyników
